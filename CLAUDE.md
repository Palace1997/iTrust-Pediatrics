## Session Management

When this conversation is getting long (many back-and-forth turns, large code changes, or context feels heavy), proactively:

1. Notify the user: "This session is getting long — I'll create a handoff file so we can continue fresh."
2. Create a `SESSION-HANDOFF.md` in this project folder with:
   - **What was built/changed** — list of accomplishments
   - **Current state** — what's working, what's not
   - **What's left to do** — remaining tasks as a checklist
   - **Important decisions made** — so they aren't revisited
   - **Key files** — the most important files to look at first
   - **Known issues** — anything broken
3. Tell the user to start a new session and say: "Read SESSION-HANDOFF.md and continue where we left off"

Do this BEFORE the context becomes a problem, not after. Better to hand off early than to lose work.
